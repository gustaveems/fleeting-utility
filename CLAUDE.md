# Fleeting Utility — agent guide

Narrative immersive sim, Godot 4.7 (GDScript 2.0), fixed angled isometric 2.5D.
Story (canonical, read before any narrative work): `docs/STORY.md`. Look: `docs/references/notes.md`. Original brief: `MASTER_BRIEF.md`. Mechanics: `GAME_SPEC.md`. Roadmap and tickets: `docs/`.

## Commands
```bash
godot --headless --import                       # Import Gate: after ANY new/renamed class_name
tools/run_all.sh                                # lint + format check + every verify/probe (exit≠0 on fail)
godot --headless --path . -s tools/<name>.gd    # one verify script
godot --path . -s tools/capture_states.gd       # windowed: PNG per lighting state → tools/out/
.venv/bin/gdformat src tools                    # format (gdtoolkit 4 lives in .venv/)
```
`.venv` missing → `python3 -m venv .venv && .venv/bin/pip install 'gdtoolkit==4.*'`.

## Ironclad rules
1. **Import Gate.** A new or renamed `class_name` is invisible until `godot --headless --import` runs. Say so whenever you add one.
2. **Hidden ≠ gone.** `visible = false` leaves child `CollisionShape3D`s in physics, Area3Ds monitoring, and `_process` / audio / particles running. Deactivating a world must disable shapes and set `process_mode`. Restoring must NOT blanket-enable shapes that gameplay disabled on purpose.
3. **No string node paths** in `src/` (`get_node("A/B")`, `$A`, `find_child("x")`). Use `@export` refs or refs handed over by the bootstrap. Test scripts in `tools/` may use paths via the harness `node()`.
4. **Verified APIs only.** No invented properties (e.g. `tonemap_exposure`, not `exposure_multiplier`; shaders use `uniform sampler2D screen_texture : hint_screen_texture;`). Godot 4 `Decal` projects along local −Y. Unsure? Use the harness `check_property_exists()`.
5. **Lint clean.** `gdlint` and `gdformat --check` must pass (`gdlintrc`). Member order: signals → enums → consts → static vars → @export → public vars → private vars → @onready.

## Architecture
- `src/data` Resources · `src/logic` state machines/controllers · `src/presentation` visuals/audio/UI · `src/player` movement/camera · `src/bootstrap` composition root.
- `scenes/workspace.tscn` (the game; tests boot it directly) is one Node3D running `workspace_bootstrap.gd`, which builds **everything in code** through modules in `src/bootstrap/modules/` (core, apartment, player, valley, narrative, audio, vfx, ui, settings, persistence); `scenes/prologue.tscn` is separate. Each module overrides `create → wire → attach → post_attach` (`BootstrapModule`), and each phase runs across all modules before the next, so every export is set before any `_ready`. Register nodes on `BootstrapContext`. A new system (audio, VFX, persistence) gets a new module.
- **Worlds** (apartment, valley, park) are `WorldRoot`s: use `set_active()` to swap and `suppress(node)` to remove a prop for good. Never toggle `visible` or shapes by hand.
- **Locks**: `player.lock_input(owner)` / `interaction.lock(owner)` with a named owner (`LockSet`). The bools are read-only.
- **Physics layers**: `PhysicsLayers` consts only. Player sensors use `PhysicsLayers.make_player_sensor(area)`.
- **Movement is free-roam everywhere** (velocity, `move_and_slide`). Grid-snapped stepping was rejected after playtesting (2026-10-11). The grid survives only as data (bench worktop, clutter spawn points). The old grid pipeline (`Main.tscn`, `GameBootstrap`, `GridMover`…) was deleted. `assets/shaders/_salvage/perception_post.gdshader` is kept as T11 input.
- Logic scripts emit signals and never own audio/VFX nodes. Presentation listens.
- **Narrative phase**: `GameFlow.phase_changed` is the one arc signal (MASTER_BRIEF order; the ambulance is armed only by the dual visions).
- **Audio** (T10): buses come from `AudioBuses.register()`. `World` carries Ambience and SFX plus the crash low-pass/overdrive; UI and Music bypass it. `AudioDirector` owns all sound. Ambient beds are children of their `WorldRoot` and pause with it. Cues come by name from a `SoundBank` (`ProceduralAudio.default_bank()` placeholders; a .tres of real files overrides per name). Audition the cues with `godot --headless --path . -s tools/export_sounds.gd`, which writes to `tools/out/sounds/`.
- **Post-FX** (T11): `ScreenEffects` is the ONE screen pass: crash CA/blur/tremor, step shake, the High-Focus look, the soft-boundary vignette and grain. `motion_scale` / `distortion_scale` are the T13 accessibility knobs. Do not add a second screen-reading pass.
- **VFX** (T11): `VfxDirector` parents dust (apartment) and leaves (valley) into their `WorldRoot`. Particles freeze via `speed_scale`, because GPU particles ignore `process_mode`. In the dream the camera switches to `set_dream_framing(true)`, so the statues fit in frame.
- **Save/load** (T12): `Persistence` writes a versioned JSON checkpoint to `user://save.json` on reaching WORKSPACE/RANSACKED/SCARRED and on quit, and auto-loads on boot (T13's menu will ask instead). F9 wipes it. Restoring goes through manager restore APIs that don't replay beats: `apply_ransack(seed, false)`, `restore_scarred()`, `mark_realized()`, `GameFlow.restore()`. New saveable state means a schema field plus `apply()` ordering, and bump `VERSION` if the shape changes (additive optional fields with defaults do not). Saves are written with `JSON.stringify(..., full_precision=true)`; the default rounds floats. World randomness that must survive a reload uses a saved seed (`ransack_seed`, `decal_seed`). `SettingsStore` (ConfigFile) is separate from the save. Tests use `TEST_SAVE_PATH`, never the real save; `reboot()` relaunches in-process.
- **Menu & settings** (T13): the main scene is `scenes/boot.tscn` (`Boot`): a splash that synthesizes the sound bank, then Continue / New Game (asks before erasing) / Settings / Quit. In game, Esc opens `PauseMenu`; quitting saves at a checkpoint. Settings live in `GameSettings.current()` (persisted via `SettingsStore`, separate from the save). Every control writes through its setters, and `SettingsApplier` applies them live. Player bus VOLUMES are settings; game-driven level changes must use bus EFFECTS (e.g. the Ambience duck Amplify). Game code awaiting SceneTree timers passes `process_always=false` so pause freezes it. Tests isolate settings like saves; `_scene_path()` lets a probe boot the menu.
- **Cycles** (playtest): each scarred reset ends on `EndCard`, which offers Renew the lease (`LeaseRenewal.renew()`: every manager's `reset_cycle()`; the scars escalate: the entropy rate compounds ×1.5 per reset, the room starts more decayed, the stash shrinks) or Walk away (epilogue, save cleared, menu). A new narrative system must implement `reset_cycle()` and be called from `LeaseRenewal`.
- **Days & mastery** (T14, loops 1–2 of Alain's six-loop design; see `docs/tickets/TICKET-14.md`): `DayCycle` counts days. `Cot` sleep starts a night dream, and a calm return is morning: day+1, a gentle wake, and the lease reclaims the works. Collapse dreams never advance the day. `Easel`: hold E to paint, with `PaintedWork` painting his state (vividness, smear, flatness, coherence = skill). The verdict is never satisfied, three hooks on the west wall, skill persists and outlives the works. The remaining loops (status, self-belief, forgetting/confession, techno promises) are later tickets.
- **Prologue** (T15, Phase A previs; spec `docs/tickets/TICKET-15.md`): `scenes/prologue.tscn` (`Prologue`) is a greybox film that New Game plays before the game. All timing and framing live in `PrologueScript` data: the route, 15 shots, lines, billboards. The film is fully cinematic (no first-person POV): one camera glides into each shot over `blend` s unless it says `cut`. Modes are EXT_FIXED / EXT_PATH / EXT_FOLLOW (it can fly through his carriage) / INTERIOR (handheld shake scaled by `motion_scale`) / WALK_FOLLOW / TOP_TRACK. `gaze` names the beat a shot frames, and street `events` (`PrologueAvenue.trigger`: the car, the crowd). The end walk (`PrologueAvenue`) follows Alain's sketch (`docs/references/sketch_walk_layout.png`) as a `PATH` polyline, and a shot's `w` is a fraction of it. If you change `ROUTE`, update `END_OF_LINE` (the probe checks it against the curve length). The city is generated to keep every shot's sightline clear (`_sightlines()`). `ColossusFigure` builds both the gold cheap copy and the stone dream colossi. Review frames with `godot --path . -s tools/capture_prologue.gd`. Phases B–D (layout, look dev, sound) replace the greybox; the director and shot data stay. Phase E: `Prologue.finish()` sets `LeaseSigning.pending`, so the game opens on the lease (hold a fresh E to sign; input is locked until then). Booting the game directly or via Continue never shows it.
- **Playability gate**: `tools/probe_playability.gd` encodes the playtest failures (drug obtainable, relief after soothing, prompts explain, window beat, calm Continue, the walk blink). Keep it green.
- Soft boundaries (vignette/fog), never invisible walls.

## Testing
- Every verify script extends `tools/lib/verify_harness.gd` and overrides `_run()` and `_title()`. Use `check()`, `wait()`, `tap_action()`, `live_shapes()`, `ray_hits()`, `capture()`.
- Headless: the script IS the tree (no `get_tree()`), `_process` is unthrottled, so time with `wait()`, never frame counts.
- Write the failing check first (red), then fix.
- `tools/probe_world_isolation.gd` is the regression gate for rule 2 and interactable detection.
